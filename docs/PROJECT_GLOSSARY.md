# CareFlow — Project Glossary

## Term| Meaning
Event log| A collection of timestamped activities associated with patient cases
Case ID| A unique identifier for a simulated patient journey
Activity| A recorded step in a patient pathway
Timestamp| The date and time when an activity occurs
Process mining| Analysis of event logs to discover and understand process behaviour
Process map| A visual representation of activities and their transitions
Directly-follows relationship| A relationship between two activities occurring consecutively in a case
Loopback| A repeated activity or return to an earlier workflow step
BigQuery| Google's cloud data warehouse
SQL| A language used to query and manipulate relational data
dbt| A tool for transforming and testing data using SQL
PM4Py| A Python library for process mining
pandas| A Python library for data manipulation and analysis
Streamlit| A Python framework for interactive data applications
Power BI| A business intelligence and data visualisation platform
Data validation| Checking data for completeness, consistency and correctness
Scenario comparison| Comparing analytical results from two simulated workflows
Pathway duration| Elapsed time between the first and last event of a patient case

## Project Context

These terms are used within CareFlow's simulated emergency-room process-mining workflow.

All patient journeys and analytical results are simulated.
