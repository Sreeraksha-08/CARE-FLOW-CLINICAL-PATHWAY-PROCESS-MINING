# CareFlow — GitHub Release Checklist

## Documentation

- [ ] README describes the completed project.
- [ ] Day 21 release notes are included.
- [ ] Setup instructions are documented.
- [ ] Simulated-data limitations are clearly stated.

## Project Files

- [ ] Source code is included.
- [ ] Final analytical outputs are included where appropriate.
- [ ] Dashboard files are included.
- [ ] No virtual environment or temporary cache files are included.

## Data and Privacy

- [ ] Only simulated patient data is used.
- [ ] No credentials, API keys or service-account files are published.
- [ ] No real patient information is included.

## Final Validation

- [ ] Python files are reviewed.
- [ ] Required dependencies are documented.
- [ ] Tests and data-quality checks are reviewed.
- [ ] Dashboard is reviewed.
- [ ] Git changes are reviewed.

## Publishing

- [ ] Confirm the intended branch.
- [ ] Review the files to be committed.
- [ ] Obtain approval before committing and pushing.
- [ ] Create a GitHub release only after final approval.
