# CareFlow Solo Work Plan

## Project Duration

12 October 2026 – 5 November 2026

## Working Method

- Maintain one individual GitHub repository.
- Work on the `main` branch.
- Make one genuine commit per day as required by the project plan.
- Document progress and problems.

## Project Modules

1. **Simulator** — generate simulated patient event logs.
2. **Warehouse** — store raw events in BigQuery.
3. **Transformation** — clean data using dbt and SQL.
4. **Process Mining** — discover workflows using PM4Py.
5. **Dashboard** — present findings using Power BI or Looker Studio.

## Development Order

1. Repository setup and documentation.
2. Python environment and simulator design.
3. Event generation and validation.
4. Warehouse and data transformation.
5. Process discovery and bottleneck analysis.
6. Dashboard, evaluation, report, and presentation.

## Data Safety

Use simulated patient data only. Never commit credentials or secret files.
