# Day 21 — Dashboard Integration

## Purpose
Prepare consistent analytical outputs for the CareFlow dashboard.

## Scenario comparison
Compare simulated before-and-after patient journeys using:
- Number of patient cases
- Total event records
- Repeated Triage cases
- Loopback rate
- Average pathway duration

## Activity comparison
Compare event counts for each clinical activity.

## Generated outputs
- analysis/final_outputs/scenario_comparison.csv
- analysis/final_outputs/activity_comparison.csv

## Limitation
The comparison uses simulated patient journeys and does not
demonstrate actual hospital performance or clinical improvement.
