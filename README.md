# CareFlow: Clinical Pathway Process Mining

## Project Overview

CareFlow is an individual healthcare operations analytics project.

## Problem Statement

Average waiting times alone may not reveal where patients experience delays.

## Objectives

- Generate simulated Emergency Room event logs.
- Store event data in Google BigQuery.
- Clean and transform data using dbt and SQL.

## Technology Stack

- Python and pandas
- Google BigQuery and SQL
- PM4Py
- Git and GitHub

## Data Privacy

This project uses simulated data only.
